# Быстрый старт

## Шаг 1: Установка зависимостей

```bash
cd mobile-app
npm install
```

## Шаг 2: Установка Expo CLI (если еще не установлен)

```bash
npm install -g expo-cli
```

Или используйте npx (не требует установки):

```bash
npx expo start
```

## Шаг 3: Запуск приложения

```bash
npm start
```

## Шаг 4: Запуск на устройстве

### Вариант 1: Через Expo Go (рекомендуется для тестирования)

1. Установите **Expo Go** на ваш телефон:
   - [iOS App Store](https://apps.apple.com/app/expo-go/id982107779)
   - [Google Play Store](https://play.google.com/store/apps/details?id=host.exp.exponent)

2. Запустите `npm start`
3. Отсканируйте QR-код:
   - **iOS**: Откройте камеру и наведите на QR-код
   - **Android**: Откройте Expo Go и нажмите "Scan QR code"

### Вариант 2: На эмуляторе

**Android:**
- Установите Android Studio
- Создайте эмулятор
- Запустите `npm start` и нажмите `a`

**iOS (только на macOS):**
- Установите Xcode
- Запустите `npm start` и нажмите `i`

## Возможные проблемы

### Ошибка с react-native-maps

Если возникают проблемы с картами, убедитесь что установлены все зависимости:

```bash
npm install react-native-maps expo-location
```

### Проблемы с портами

Если порт занят, используйте:

```bash
npx expo start --port 8081
```

### Очистка кэша

```bash
npx expo start -c
```

## Тестирование ролей

При входе в приложение выберите роль:
- **Администратор** - полный доступ
- **Водитель** - панель водителя
- **Житель** - создание заказов

Пароль не требуется для демо-версии - просто выберите роль и нажмите "Войти".

# Taza qala Mobile App

Мобильное приложение для отслеживания мусоровозов (Android и iOS)

## Особенности

- 📱 **Кроссплатформенное** - работает на Android и iOS
- 👨‍💼 **Панель администратора** - управление системой
- 🚛 **Панель водителя** - управление маршрутом и заказами
- 🏠 **Панель жителя** - создание заказов на вывоз мусора
- 🗺️ **Интерактивная карта** - отслеживание мусоровозов и мусорок
- ⛽ **Отслеживание бензина** - индикатор уровня топлива
- 🎨 **Современный дизайн** - сине-фиолетовая цветовая схема

## Установка и запуск

### Требования

- Node.js 16+
- npm или yarn
- Expo CLI (установится автоматически)

### Установка зависимостей

```bash
cd mobile-app
npm install
```

### Запуск приложения

```bash
npm start
```

После запуска откроется Expo Dev Tools. Вы можете:

1. **Нажать `a`** - запустить на Android эмуляторе
2. **Нажать `i`** - запустить на iOS симуляторе (только на macOS)
3. **Отсканировать QR-код** - запустить на физическом устройстве через Expo Go

### Запуск на физическом устройстве

1. Установите приложение **Expo Go** из App Store (iOS) или Google Play (Android)
2. Запустите `npm start`
3. Отсканируйте QR-код камерой (iOS) или через Expo Go (Android)

## Роли пользователей

### Администратор
- Просмотр всех метрик
- Управление заказами
- Просмотр карты со всеми мусоровозами
- Статистика работы

### Водитель
- Просмотр текущего заказа
- Предстоящие заказы
- Уровень бензина
- Навигация по карте

### Житель
- Создание заказов на вывоз мусора
- Просмотр своих заказов
- Статус заказов

## Технологии

- **React Native** - фреймворк для мобильной разработки
- **Expo** - платформа для разработки React Native приложений
- **React Navigation** - навигация между экранами
- **React Native Maps** - карты и геолокация
- **React Native Paper** - UI компоненты

## Сборка для продакшена

### Android

```bash
expo build:android
```

### iOS

```bash
expo build:ios
```
